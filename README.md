### FitTrack Pro - Workout Tracker Dashboard

FitTrack Pro is a dynamic, responsive web application designed to help fitness enthusiasts log, track, and analyze their workout routines. The application features a clean user interface that computes live fitness metrics and maintains a detailed history of completed exercises.

✨ Features

* Dynamic Analytics Cards: Instantly recalculates total workouts completed and the cumulative weight lifted across all exercises.
* Interactive Workout Logger: A clean form layout that takes user inputs for exercise name, weight, and repetitions with seamless validation.
* Real-time History Management: A structured data table that displays past entries with individual record deletion capabilities.
* Fully Responsive UI: A modern dashboard sidebar system optimized for desktop browsers.

🛠️ Tech Stack

* Frontend: HTML5, CSS3
* Scripting: Vanilla JavaScript (ES6+)
* Version Control: Git & GitHub
